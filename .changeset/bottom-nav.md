Add `BottomNav` and `BottomNavItem`, the phone's primary navigation on daisyUI's `dock`: a named navigation landmark of links, each an icon over its label, the current one `aria-current="page"` from the components context, with an optional badge named in words. While fixed it sets `--bottom-nav-height` on the document root for the page's padding. `tones.ts` gains `dockSize`.
