Flowchart & Diagram Building Blocks Demo

This demo showcases the low-level building blocks for creating flowcharts, diagrams, and entity relationship diagrams using the @thomasfosterau/charts library.

1. Basic Shapes

Fundamental shapes used in flowcharts and diagrams: boxes, diamonds, ellipses, parallelograms, and custom polygons.

2. Connectors and Arrows

Various types of connectors for linking diagram elements: straight arrows, curved lines, and multi-segment paths.

3. Simple Flowchart Example

A complete flowchart demonstrating a decision-making process using the building blocks.

4. Entity Relationship Diagram Example

A simple ERD showing entity relationships with boxes and connectors.
