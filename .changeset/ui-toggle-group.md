Add `ToggleButton` and `ToggleGroup` (ui family) on bits-ui `Toggle` / `ToggleGroup`. `ToggleButton` is an `aria-pressed` button with an optional `pressedIcon` and a type-enforced `label` when icon-only. `ToggleGroup` is a segmented control (`type="single"`: a radiogroup where arrows move and select, with `required` to keep one selected) or a set of independent toggles (`type="multiple"`), with `labelId` for `FormField`, `name` for form submission, `block`, `showCheck` and an opt-in `tooltip` for icon-only items.
