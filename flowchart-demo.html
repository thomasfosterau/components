Flowchart & Diagram Building Blocks

Usage guide for the flowchart and diagram primitives in @thomasfosterau/charts

Important: The shape and connector components must be nested inside a <Chart> component to work properly. They rely on Svelte's context API to access the renderer.

Proper Usage in Svelte

Shape and connector components should be used within a Svelte component file (.svelte) and nested inside a <Chart> component:

<script>
  import { 
    Chart, Box, Diamond, Ellipse, 
    Parallelogram, Text, Arrow 
  } from '@thomasfosterau/charts';
</script>

<Chart width={600} height={400} renderTarget="svg">
  <!-- Start node -->
  <Ellipse centerX={50} centerY={15} radiusX={8} radiusY={6} 
           fill="#e8f5e9" stroke="#388e3c" strokeWidth={2} />
  <Text x={50} y={15} text="Start" />
  
  <!-- Arrow -->
  <Arrow startX={50} startY={21} endX={50} endY={30} />
  
  <!-- Process box -->
  <Box x1={40} y1={30} x2={60} y2={45} 
       fill="#e3f2fd" stroke="#1976d2" strokeWidth={2} />
  <Text x={50} y={37.5} text="Process" />
  
  <!-- Arrow -->
  <Arrow startX={50} startY={45} endX={50} endY={52} />
  
  <!-- Decision diamond -->
  <Diamond centerX={50} centerY={62} width={20} height={20}
           fill="#fff3e0" stroke="#f57c00" strokeWidth={2} />
  <Text x={50} y={60} text="Valid?" fontSize={12} />
</Chart>

Available Components

Shape Components

  • Box - Rectangle with optional rounded corners
  • Diamond - Diamond shape for decision nodes
  • Ellipse - Ellipse/oval for terminal nodes
  • Parallelogram - Parallelogram for input/output
  • Polygon - Custom polygon from point array
  • Text - Text labels with styling options

Connector Components

  • Arrow - Straight line with arrow head
  • CurvedLine - Bezier curve connector
  • ConnectorLine - Multi-segment line

Coordinate System

  • Positions: Use Pancake coordinates (0-100 as percentages)
  • Sizes: Use pixel units (radius, strokeWidth, arrowSize, etc.)

Render Targets

All components support multiple render targets:

  • svg - SVG rendering (client-side only)
  • canvas - Canvas 2D rendering for high performance
  • webgpu - GPU-accelerated (experimental, not fully implemented)
Note: Components currently use onMount() and do not support server-side rendering (SSR).
