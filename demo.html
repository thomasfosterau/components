@thomasfosterau/charts

A declarative Svelte charting library with multi-target rendering

Key Features

🎨 Multiple Render Targets

SVG for SSR, Canvas for performance, WebGPU for GPU acceleration

🥞 Pancake Coordinates

Percentage-based (0-100) coordinate system for renderer-agnostic layouts

📊 Rich Chart Types

Line, Bar, Area, Scatter, Pie/Donut charts with more coming

⚡ High Performance

Choose Canvas or WebGPU for large datasets and real-time updates

🎯 Type-Safe

Full TypeScript support with comprehensive type definitions

🎨 Themeable

Built-in themes and color palettes with custom theme support



Example: SVG Rendering

Charts are created declaratively using Svelte components 

<Chart width={600} height={400} renderTarget="svg">
  <Line {data} x="x" y="y" stroke="#4299e1" />
  <Axis {scale} type="x" gridLines />
  <Axis {scale} type="y" gridLines />
</Chart>

Installation

Install via npm or Bun 

npm install @thomasfosterau/charts

# or

bun add @thomasfosterau/charts

Inspired By

This library combines the best ideas from Swift Charts (declarative API), D3.js (scales and transformations), Pancake Charts (SSR-compatible coordinates), and the Svelte ecosystem (reactive simplicity).
