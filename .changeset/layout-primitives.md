Add the layout primitives `VStack`, `HStack`, `Cluster`, `Grid`, `Spacer` and `Fits` (layout family), and the spacing scale they share (`layout/space.ts`: `Gap`, `MinItem`, `FitsBreakpoint` and their literal class tables). `Grid` sizes columns by minimum item width. `Fits` shows the first of several layouts that fits its container, through CSS container queries. A `ul` / `ol` stack restores `role="list"`.
